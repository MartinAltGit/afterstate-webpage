## How to paste

1. Open **Settings → Policies**
2. For each policy below, copy **only the HTML inside** the ` ```html ` fence
3. **Do not copy** the `**Shopify field:**` line, the ` ```html ` line, or the closing ` ``` `
4. Paste into Shopify’s policy editor (rich text / HTML), then Save
5. Confirm `/policies/privacy-policy` etc. show formatted paragraphs — not raw tags
6. Optional: tag sale products with **`Final Sale`**

If you paste the markdown wrappers, the storefront will show code instead of the policy. The Hydrogen app falls back to the same copy when Shopify bodies are empty or look mangled.
